# RAG PDF Chatbot

A Retrieval-Augmented Generation (RAG) chatbot that answers questions from PDF documents using Google Gemini, LangChain, and FAISS.

## Features
- PDF Upload
- Text Extraction
- Vector Embeddings
- Semantic Search
- Gemini AI Responses

## Technologies Used
- Python
- Streamlit
- LangChain
- Google Gemini
- FAISS
 
- ## Installation

pip install -r requirements.txt

## Create .env file

GOOGLE_API_KEY=your_api_key

## Run

streamlit run app.py
